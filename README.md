# Gracias por ser mi equipo de trabajo

Página de agradecimiento con modelos 3D del equipo, hecha con HTML, CSS y JavaScript usando [three.js](https://threejs.org/).

## Estructura

```
index.html          Estructura de la página
css/estilos.css     Estilos (modo claro y oscuro)
js/datos.js         Lista del equipo: nombre, colores, pelo, lentes
js/ayudas.js        Funciones para dibujar formas básicas
js/props.js         Objeto 3D de cada rol
js/personaje.js     Cómo se arma un personaje
js/escena.js        Escena, cámara y luces
js/logos.js         Logos flotantes del stack
js/equipo3d.js      Creación y posiciones del equipo
js/interacciones.js Hover, click y confeti
js/animacion.js     Bucle de animación
```

## Ejecutar

Abrir `index.html` en el navegador (necesita internet para cargar three.js).
